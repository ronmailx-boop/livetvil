# טלוויזיה ישראלית חי 📺

אפליקציית ווב (PWA) לצפייה בשידור חי של ערוצי טלוויזיה ישראליים, ישירות מהדפדפן — בלי התקנה, בלי צד שרת.

## תכונות

- **שידור חי** של ערוץ **11 (כאן)** וערוץ **13 (רשת)**, עם החלפה מהירה בין הערוצים.
- **מנגנון fallback אוטומטי** — לכל ערוץ יש כמה כתובות סטרימינג; אם אחת נכשלת, האפליקציה עוברת אוטומטית לכתובת הבאה.
- **URL מותאם אישית** — ניתן להזין כל קישור m3u8 ולנגן אותו ישירות.
- **PWA** — ניתן להתקין את האפליקציה על מסך הבית (מובייל/דסקטופ) ולהשתמש בה כמו אפליקציה עצמאית, כולל תמיכה ב-Service Worker לעבודה אופליין חלקית.
- **עיצוב מותאם למובייל (Mobile-First)** עם תמיכה מלאה בעברית ו-RTL.

## טכנולוגיה

- HTML/CSS/JavaScript טהורים — ללא framework וללא build step.
- [hls.js](https://github.com/video-dev/hls.js) לניגון סטרימינג HLS (m3u8) בדפדפנים שאינם תומכים בו באופן טבעי.
- Service Worker (`sw.js`) + `manifest.json` להתנהגות PWA.

## מבנה הקבצים

| קובץ | תיאור |
|---|---|
| `index.html` | כל האפליקציה — מבנה, עיצוב ולוגיקת הניגון |
| `manifest.json` | הגדרות ה-PWA (שם, אייקון, צבעים) |
| `sw.js` | Service Worker לשמירת קבצים במטמון |
| `icon.png` | אייקון/לוגו האפליקציה |

## הרצה

פשוט לפתוח את `index.html` בדפדפן, או להגיש את התיקייה כאתר סטטי (למשל GitHub Pages).

## הערה לגבי יציבות השידורים

כתובות הסטרימינג הן כתובות ציבוריות/מראות של הערוצים ואינן בשליטת האפליקציה — ייתכן שישתנו או ייפלו מדי פעם. אם ערוץ לא עולה, ניתן לנסות את הסטרימים החלופיים (הנקודות מתחת לנגן) או להזין כתובת m3u8 עדכנית בשדה ה-URL המותאם אישית.
